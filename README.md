# I-ITSM
## Intelligent IT Service Management & Incident Resolution System

An IT service management system for reporting, tracking, assigning, prioritising and resolving incidents.

## Technology Stack

### Backend
- Java 21
- Spring Boot 3.5.x
- Maven
- Spring Security and JWT
- Spring Data JPA
- PostgreSQL
- Flyway

### Frontend
- React
- Vite
- JavaScript
- React Router
- Recharts

### Testing
- JUnit 5
- Mockito
- MockMvc
- Vitest
- React Testing Library

## Main Features

- Incident lifecycle management
- Role-based access control
- Incident prioritisation
- Technician assignment strategies
- SLA tracking and violation detection
- Notifications
- Audit trail
- Incident search and filtering
- Dashboard and reports
- Duplicate incident detection
- Technician recommendation

## User Roles

- Employee
- Technician
- Administrator

## Project Structure

- `backend/` — Spring Boot application
- `frontend/` — React application
- `docs/` — Design, API contracts, testing and project documentation
